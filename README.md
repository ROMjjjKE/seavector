# ООО «Морской вектор» — корпоративный сайт

Светлая корпоративная версия: 17 страниц, чистый HTML/CSS/JS, без сборщиков.

## Структура
index, about, services, services-avto, services-temp, services-int, services-warehouse,
services-container, fleet, tlk, geography, clients, partners, career, contacts, news, privacy.

## Что внутри
- Подбор перевозки (направление, груз, вес) с расчётом транспорта, режима и документов.
- Температурная шкала −25…+25 °C с переключением режимов.
- Схема направлений от терминала и таблица расстояний.
- Вакансии аккордеоном + сборка отклика для WhatsApp.
- Мобильная полоса: позвонить, WhatsApp, Viber, Telegram.

## Публикация
GitHub Pages, ветка main, корень репозитория. Robots и sitemap настроены на seavector.by.
